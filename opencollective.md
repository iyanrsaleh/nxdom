# Panduan Pendaftaran Open Collective untuk NXDOM

Kesalahan umum saat mendaftar Open Collective adalah mengisi form untuk "Perusahaan Legal" (Organisasi). Sebagai pembuat *open source*, Anda cukup membuat **"Collective"** (Kolektif).

Berikut adalah panduan tepat langkah demi langkahnya:

## Langkah 1: Memulai Pendaftaran
1. Buka tautan ini secara langsung: **[https://opencollective.com/create](https://opencollective.com/create)**
2. Anda akan melihat pertanyaan *"What are you creating?"* (Apa yang sedang Anda buat?).
3. Pilih opsi **"Open Source Project"** (Proyek Open Source). 
   *(Jangan memilih "My Community" atau "Organization" agar Anda tidak ditagih dokumen legal PT/Yayasan).*

## Langkah 2: Verifikasi GitHub
Setelah memilih "Open Source Project", sistem akan mengarahkan Anda ke GitHub:
1. Klik **"Verify with GitHub"**.
2. Pilih akun atau repositori yang memuat karya NXDOM Anda (seperti `nxc` atau `teritipdb`).
3. Ini berfungsi sebagai bukti bahwa Anda adalah pengembang (*maintainer*) asli dari proyek tersebut.

## Langkah 3: Mengisi Data "Collective" NXDOM
Setelah verifikasi selesai, Anda akan diminta mengisi data publik untuk halaman donasi Anda:
*   **Name (Nama):** `NXDOM` atau `Nusantara eXtreme Development Object Model`
*   **URL:** `nxdom` *(nantinya link Anda menjadi opencolective.com/nxdom)*
*   **Description:** `Developing core systems, TeritipDB, desktop SDKs, and AI agents for the global open source community.`
*   **Website:** `https://nxcodeobject.github.io/nxdom/` (Link web baru kita).

## Langkah 4: Memilih Fiscal Host (Penting!)
Di tahap akhir, Anda akan ditanya siapa yang akan menjadi *Fiscal Host* (Payung Hukum/Penyimpan Dana) Anda.
*   Pilih **Open Source Collective 501(c)(6)**.
*   **Catatan:** Mereka mensyaratkan proyek Anda memiliki minimal 100 *stars* di GitHub. Jika salah satu proyek Anda sudah memilikinya, permohonan Anda akan disetujui dalam 1-2 hari kerja. Dana sponsor dari luar negeri akan masuk ke kas mereka, dan Anda tinggal menariknya kapan saja ke rekening bank di Indonesia.

---

### Skenario Alternatif: Bagaimana jika "Open Source Collective" Menolak karena Star GitHub Belum Cukup?

Jika *stars* Anda belum mencapai 100, jangan khawatir. Anda masih bisa menggunakan Open Collective secara mandiri (**Independent Collective**). 

Caranya: 
Kembali ke halaman profil, dan pilih jalankan proyek sebagai **Independent**. Barulah pada saat ini Anda harus mengisi form legal seperti yang sempat Anda tanyakan sebelumnya. Isilah dengan data pribadi Anda:

*   **Country of Incorporation:** `🇮🇩 Indonesia`
*   **Currency:** `USD`
*   **Legal Name:** *(Isi dengan NAMA LENGKAP Anda sesuai KTP/Rekening Bank, misal: Iyan R. Saleh)*
*   **Public Name:** `NXDOM`
*   **Your Role:** `Founder`

Dengan jalur Independen ini, uang donatur akan ditagih oleh sistem Open Collective, dipotong sedikit biaya admin server mereka, lalu sisanya akan langsung dikirim (ditransfer) ke rekening bank pribadi Anda di Indonesia via sistem Stripe.
