Lihat Ekosistem Misi Organisasi

Visi Kami

Menjadi komunitas pengembang teknologi terbuka yang inovatif, mandiri, dan berdaya saing global dari Nusantara.

Misi Utama

  • Mengembangkan perangkat lunak open source yang dapat dipelajari, digunakan, dan dikembangkan bersama.
  • Membangun framework dan sistem modular yang kuat, fleksibel, dan dapat diperluas.
  • Mendorong kolaborasi antara programmer, developer, administrator sistem, dan peneliti.
  • Mengembangkan standar serta dokumentasi teknis yang terbuka.
  • Membangun ekosistem teknologi Nusantara yang berkontribusi kepada komunitas global.

Struktur & Divisi

Fokus pengembangan dan riset di berbagai lapisan arsitektur teknologi.

Core

Fokus pada arsitektur inti dan perancangan model objek fundamental yang menjadi basis sistem.

Systems

Membangun sistem operasi, arsitektur server, dan infrastruktur komputasi tingkat rendah.

Framework

Menciptakan framework dan pustaka (library) pemrograman untuk mempercepat pengembangan aplikasi.

Security

Menangani keamanan aplikasi, audit kode, pencegahan eksploitasi, dan standarisasi kriptografi.

Community

Pusat kolaborasi ekosistem, penyusunan dokumentasi, dan program edukasi untuk developer.

Labs

Divisi riset dan eksperimen teknologi mutakhir, inkubasi prototipe, dan pengembangan AI.

Ekosistem Proyek

Produk open source inovatif yang lahir dan dikembangkan dari rahim komunitas kami.

Agent CLI ↗

NxCode (nxc)

AI coding agent langsung di terminal. Memiliki agent Build & Plan, paham kode via LSP, dan mendukung ekstensi MCP dengan multi-provider model.
Desktop SDK ↗

NXC Desktop SDK

SDK C++ native berbasis Qt 6. Framework aplikasi desktop super ringan tanpa Electron, dibekali jendela Fluent, PTY terminal, dan runtime bridge.
Database ↗

TeritipDB

Mesin database dokumen berbasis JSON. Cepat, ringan, dan dirancang untuk skalabilitas aplikasi modern tanpa setup yang rumit.
IDE Desktop ↗

NxCode IDE

Editor kode desktop di atas NXC SDK. Explorer, pencarian, source control, API client, database, dan terminal agen AI dalam satu jendela, dengan penyorotan sintaks lebih dari 400 bahasa.
Framework CLI ↗

NxDOM CLI

CLI untuk mengelola seluruh runtime Nxdom — Backend PHP, Desktop Electron, Mobile Expo, Web Express, dan Web statik — lengkap dengan modul siap pakai dan Agent AI bawaan multi-provider.

Prinsip Open Source

Pondasi etos kerja yang kami pegang teguh.

01
Open Development

Kode, perancangan, dan proses pengembangan kami buka secara transparan.

02
Community Driven

Kontribusi, ide, dan diskusi dari komunitas sangat dihargai dan menjadi motor penggerak.

03
Modular Architecture

Setiap sistem dibangun dari komponen independen yang dapat didaur ulang (reusable).

04
Transparent Governance

Keputusan teknis dan aturan tata kelola proyek terdokumentasi dengan baik dan adil.

05
Free & Open Licensing

Mematuhi lisensi terbuka seperti MIT, Apache-2.0, atau GPL sesuai dengan sifat proyek.
